# atividade_dados

Eu optei por utilizar a bilbioteca Pandas para a manipulação do arquivo csv : https://pandas.pydata.org/
e matplotlib para geração dos graficos : https://matplotlib.org/

primeiramente eu os campos de string para numero , e tratei erros com.
apos isso preenchi os campos vazios com as médias das respectivas colunas. 
então calculei as medias gerais, e então gerei os graficos.
